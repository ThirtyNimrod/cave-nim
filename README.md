# nim.

Daily caveman-stoic proverb cards for Instagram — an automated content pipeline
that writes a short verse, matches it to a hand-drawn line-art icon, renders a
1080x1350 card, and (after your manual review) publishes it to Instagram.

## How it works

1. **Generate** (`python main.py generate`, runs daily via GitHub Actions cron
   at 14:00 UTC): asks Gemini for a 3-line proverb plus a matching icon from the
   curated icon library, renders the card with Playwright, and commits the PNG
   and a new `database/canon.json` entry (`status: pending_review`) to `main`.
2. **Review**: check the newly committed image in `assets/rendered/`.
3. **Publish** (manual only — `.github/workflows/publish.yml`, triggered from
   the Actions tab): posts the reviewed card to Instagram via the Meta Graph
   API, then commits the resulting `ig_media_id` back to `canon.json`.

Nothing posts to Instagram automatically — publishing always requires you to
manually trigger the `publish` workflow (or run `python main.py publish`
locally), by design.

## Numbering & palettes

Posts are numbered `chapter.verse` (e.g. `nim. 1.14`), rolling to a new chapter
every 30 posts. Each post cycles through 4 fixed palettes in order (Obsidian
Chrome, Forest Tablet, Terracotta Sunset, Colonial Cobalt) — see
[`src/config.py`](src/config.py).

## Local setup

```bash
python -m venv .venv
.venv/Scripts/activate   # or source .venv/bin/activate on macOS/Linux
pip install -r requirements.txt
playwright install chromium
cp .env.example .env     # fill in your own keys, see below
```

### Try it with no API keys at all

```bash
python main.py generate --mock
```

Renders a placeholder card to `assets/rendered/_preview.png` using canned text
and a trivial icon — doesn't call Gemini, doesn't touch `canon.json`. Use this
to iterate on `templates/card_template.html` layout/fonts.

### Real generation (post 1.31 onward)

```bash
python main.py generate
python main.py status              # list posts awaiting review
python main.py publish --dry-run   # exercise the Graph API without posting
python main.py publish             # actually publish the latest pending post
```

## Required secrets

| Variable | Where it's used | How to get it |
|---|---|---|
| `GEMINI_API_KEY` | `generate` | [Google AI Studio](https://aistudio.google.com/apikey) |
| `META_ACCESS_TOKEN` | `publish` | Meta Developer app + Instagram Business/Creator account linked to a Facebook Page; long-lived token with content-publish permission |
| `IG_USER_ID` | `publish` | The numeric Instagram-scoped user id (not your @handle) |

Set these locally in `.env` (gitignored) and as **GitHub Actions repo secrets**
(Settings → Secrets and variables → Actions) for CI.

## Icon library

`assets/doodles/manifest.json` maps icon slugs to SVG files and search tags;
Gemini picks one slug per post from this list. All 18 are original single-
stroke SVGs authored for this project (fire, water, moon, mountain, storm,
spear, footprint, star, tree, stone, wind, bone, shield, pawprint, thorn,
cave, seed, snow) — add more the same way as the verse vocabulary grows.

## Known limitations

- Committing a PNG per day grows repo history over time (~100-300MB/year) —
  fine at one post/day, worth revisiting later (Git LFS or archival) if needed.
- Long-lived Meta access tokens expire (~60 days) — you'll need to refresh
  `META_ACCESS_TOKEN` periodically.
